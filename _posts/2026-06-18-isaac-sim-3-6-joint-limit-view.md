> Joint limit 을 Scene 에서 시각화 하는 방법

기본 설정값을 사용하는 화면은 Joint 를 클릭하더라도 Joint 의 위치를 TF 로 보여주진 않음

![기본 화면에서는 Joint가 보이지 않음](/assets/img/posts/isaac-sim-3-6-joint-limit-view/1.png)

하지만 눈 모양 → Show By Type → Physics → Joints 를 클릭하면 Scene 에서 Joint 를 확인 할 수 있음

![Show By Type → Physics → Joints](/assets/img/posts/isaac-sim-3-6-joint-limit-view/2.png)

총 2개의 Joint 가 화면에 보이게 되며 클릭 시 해당 Joint 가 어떻게 움직이는지, 어떤 Material 과 연결되어있는지 까지 확인 가능

![Scene에 표시된 Joint](/assets/img/posts/isaac-sim-3-6-joint-limit-view/3.png)

![Joint 클릭 시 보이는 연결 정보](/assets/img/posts/isaac-sim-3-6-joint-limit-view/4.png)
