## 시뮬레이션 환경 구성

Isaac Sim 6.2.0 + Isaac Lab 3.0.0 조합으로 설치함 ( 2026-10 기준 최신 stable )

Isaac Lab 3.0.0 이 Isaac Sim 6.2.0 을 고정으로 요구해서 이 조합으로 맞췄음

conda 는 쓰지 않고 uv 만 사용함

- Python 3.12
- PyTorch 2.11 ( CUDA 13.0 )

레포 안에 uv 프로젝트( `pyproject.toml` + `uv.lock` )로 구성해 두어서 아래 한 줄이면 같은 환경이 그대로 만들어짐

```bash
uv sync
```

`isaacsim-core` 가 prerelease 패키지( `tinyobjloader` rc )를 요구해서 `prerelease = "allow"` 를 넣어줘야 설치가 됨

Isaac Lab 공식 문서에 있는 override 목록도 그대로 적용함

Isaac Lab 은 fork 하지 않고 PyPI wheel 로 받아서 쓰고, 연구 코드는 별도 레포에서 관리할 예정

GPU 는 Asus RTX 5060 Laptop 을 사용함

## 에셋 준비

[SO-101 1. 환경 구축]({% post_url 2026-10-21-so101-1-environment %}) 에서 꾸린 실제 책상 환경과 최대한 비슷하게 맞추는 게 목표

회사에서 개발과 여러 연구들을 진행하고 있는데, Claude Opus 5.5 부터 Isaac Sim 에셋을 만드는 능력이 좋아져서 에셋은 LLM 을 기반으로 구축함

아래 사진은 전부 Isaac Sim RTX Path Tracing 으로 렌더링한 것

### SO-101

NVIDIA 공식 SysID USD 를 사용함 ( Isaac Lab `SO101_CFG` 와 같은 에셋, Apache-2.0 )

관절은 6개

![SO-101](/assets/img/posts/so101-4-sim-setup/so101.png)

### 테이블

Isaac Sim 에 있는 연구실 테이블을 가져와서 상판 Material 만 흰색으로 override 함

![흰색 테이블](/assets/img/posts/so101-4-sim-setup/table_white.png)

테이블은 일단 임시로 쓰는 것이고, 향후 D435 카메라로 집을 Mapping 한 후 집 위주로 환경을 구축할 예정

### 펜 ( 빨강 / 파랑 / 검정 )

Isaac Sim Office 소품에 있는 펜을 가져와서 rigid body, 질량( 10g ), convex hull 충돌을 추가함

색은 텍스처 명암은 그대로 두고 색만 바꿔서 3가지로 만들었음

### 펜꽂이

에셋 라이브러리에 쓸만한 메시가 없어서 스크립트로 직접 만들었음

검은색 타공 금속 원통이고 크기는 8 × 10cm

충돌은 안 보이는 박스 16개 + 바닥 원판으로 잡아줌

![펜꽂이](/assets/img/posts/so101-4-sim-setup/pen_holder.png)

### 테이프

Scotch 다용도 테이프( 12.7mm ) 디스펜서를 참고해서 이것도 스크립트로 만들었음

투명 케이스 + 타탄 라벨 + 호박색 테이프 + 커터 구성이고, 충돌은 몸체 원기둥 + 꼬리 박스로 잡아줌

![테이프](/assets/img/posts/so101-4-sim-setup/tape.png)
